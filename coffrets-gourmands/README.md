# Les Coffrets Gourmands

Maquette de site en HTML/CSS (BTS SIO, bloc 1, mission 2). Trois pages reliées par un menu commun :

- `index.html` : accueil, présentation de Charlotte, ardoise des prix
- `coffrets.html` : contenu détaillé des 5 coffrets, vidéo, tableau récapitulatif, bon de commande
- `producteurs.html` : tableau des producteurs (nom, catégorie, horaires, produit signature)

Ouvrir `index.html` dans un navigateur suffit, aucune installation n'est nécessaire.

## À remplacer avant de rendre

Les images du dossier `images/` sont des visuels provisoires marqués « photo à remplacer ». Garder les mêmes noms de fichiers et les remplacer par des photos libres de droits (Unsplash, Pexels, Pixabay), en notant la source de chacune :

| Fichier | Ce que la photo doit montrer |
|---|---|
| `images/coffret-gouter.jpg` | coffret ouvert, pâte à tartiner, sablés, confiture de fraise |
| `images/charlotte-ficelle.jpg` | mains qui nouent une ficelle autour d'une boîte kraft |
| `images/coffret-petit-dejeuner.jpg` | confiture, granola, thé |
| `images/coffret-dejeuner.jpg` | bocal de lentilles, huile, vinaigre, épices |
| `images/coffret-anniversaire.jpg` | boîte fermée avec ruban rouge et carte |
| `images/coffret-surprise.jpg` | boîte fermée avec étiquette kraft |
| `images/verger-chaudron.jpg` | confiture qui cuit dans un chaudron en cuivre |

Fichiers à ajouter (pas encore présents) :

- `audio/marche-samedi.mp3` : ambiance de marché, environ 1 minute (Pixabay, rubrique effets sonores)
- `videos/preparation-coffret.mp4` : préparation d'un coffret ou emballage cadeau (Pexels ou Pixabay vidéos)

## Contenu fictif

Les producteurs, prix, délais et tarifs de livraison sont inventés pour l'exercice. Le formulaire de commande n'est relié à aucune adresse e-mail.
