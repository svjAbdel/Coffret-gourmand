# Les Coffrets Gourmands

Maquette de site en HTML/CSS (BTS SIO, bloc 1, mission 2). Trois pages reliées par un menu commun :

- `index.html` : accueil, présentation de Charlotte, ardoise des prix
- `coffrets.html` : contenu détaillé des 5 coffrets, vidéo, tableau récapitulatif, bon de commande
- `producteurs.html` : tableau des producteurs (nom, catégorie, horaires, produit signature)

Ouvrir `index.html` dans un navigateur suffit, aucune installation n'est nécessaire.

## Contenu fictif

Les producteurs, prix, délais et tarifs de livraison sont inventés pour l'exercice. Le formulaire de commande n'est relié à aucune adresse e-mail.
