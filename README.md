# Les Coffrets Gourmands

Site vitrine en HTML et CSS pour Les Coffrets Gourmands, l'entreprise fictive de Charlotte Bon Goût qui vend des coffrets gourmands composés à la main.

Projet de **BTS SIO 1re année**, bloc 1, mission 2 : développer la présence en ligne de l'organisation cliente.

**Voir le site : https://coffret-gourmand.netlify.app**

![Page d'accueil](docs/captures/index-ordinateur.jpg)

## Pages

| Page | Contenu |
|---|---|
| [Accueil](index.html) | Présentation de Charlotte, contenu d'un coffret, prix des 5 coffrets, infos pratiques, ambiance sonore |
| [Nos coffrets](coffrets.html) | Détail des 5 coffrets, vidéo, tableau récapitulatif, bon de commande |
| [Producteurs partenaires](producteurs.html) | Les 6 producteurs : catégorie, horaires, produit signature |

Balises utilisées : titres, paragraphes, liens, images, `audio`, `video`, boutons, tableaux, listes et formulaire.

## Ouvrir le projet

1. **Code**, puis **Download ZIP**, et extraire le dossier (ou `git clone https://github.com/svjAbdel/Coffret-gourmand.git`).
2. Dans VS Code : **Fichier**, puis **Ouvrir le dossier…**
3. Ouvrir `index.html` dans le navigateur, ou clic droit, puis **Open with Live Server**.

## Structure

```
index.html          Accueil
coffrets.html       Nos coffrets
producteurs.html    Producteurs partenaires
assets/
  style.css         Feuille de style commune
  images/           Photos
  audio/            Ambiance sonore
  videos/           Vidéo
  polices/          Polices (licence OFL)
docs/captures/      Captures d'écran
```

## Choix graphiques

- **Couleurs** tirées du métier : kraft des boîtes, brun confiture, rouge cire à cacheter pour les prix et les boutons, vert pour le bio.
- **Polices** : *Big Shoulders Display*, proche du lettrage au pochoir des caisses de marché, et *Literata* pour la lecture.
- **Mise en page** : étiquette de coffret, ardoise de prix, bon de colisage et bon de commande, plutôt qu'un modèle de site générique.
